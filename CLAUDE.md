# Правила репозитория

Здесь живут скиллы для видео-проектов. Только когда идёт работа над роликом (иначе правило не применяется). Для всего, что касается клипов (кадры, сценарий, тайминг под трек, промты для Seedance, OmniHuman, OmniFlash, ChatGPT, Nano Banana, sync.so, разговор с заказчиком, реализм героя) **сначала открывается `.claude/skills/struktura-klipa/SKILL.md` и файл по теме из его таблицы**, и только потом пишется ответ. Правила не вспоминаются, а читаются заново: пересказ из резюме беседы их теряет.

Перед отправкой промта или сценария ответ сверяется с чеклистом в начале `.claude/skills/struktura-klipa/references/promty.md`. Каждая новая правка пользователя записывается в скилл и коммитится в тот же заход. Работа идёт на ветке `claude/hopeful-johnson-mvb8op`, пул-реквесты без просьбы не создаются.

Главное правило клипов: консистентность превыше всего (персонаж, локация, свет, одежда, палитра). Её нельзя менять ради красоты кадра или идеи; подробности в `.claude/skills/struktura-klipa/references/nepreryvnost.md`, раздел 0.
