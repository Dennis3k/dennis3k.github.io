# Проверка

Смотреть глазами. Почти ни один из найденных дефектов не был виден из кода.

---

## 1. Стиллы

```bash
python3 render.py --fmt 16x9 --scale 0.6 --stills 2.45,4.10,5.80,9.30,12.60
```
Масштаб 0.6 и уполовиненные подкадры — кадр за пару секунд. На этом этапе ловится композиция, кадрирование, читаемость текста.

---

## 2. Контактный лист

```bash
python3 sheet.py out/sheet.png out/still_*.png
python3 contact.py            # кадр каждые 0.4 с по всему хронометражу
```
Лист по всему ролику отвечает на вопрос, на который не отвечают отдельные кадры: **держит ли ритм**. Провалы и повторы видно сразу.

---

## 3. Покадровые полоски

```bash
python3 qc.py frames/16x9        # 12 кадров подряд вокруг каждого удара
```
Обязательные точки: удар, касание, дроп, пролёт, геройский аккорд и **каждый стык сцен**. Ловит пропущенные кадры, двойную экспозицию на стыках, ступенчатый моушн-блюр.

---

## 4. Кривая яркости

Тот же скрипт печатает среднюю яркость по кадрам и самые большие скачки.

Как читать:
- скачок там, где задумана вспышка, — норма;
- скачок в спокойном месте — дефект;
- несколько кадров подряд почти чёрных — сцена не передала эстафету;
- средняя яркость выше 0.85 дольше 4–5 кадров — пересвет, на телефоне будет резать глаз.

---

## 5. Один круг правок

Собери **все** дефекты в список и почини разом. Причина жёсткая: полный прогон и сборка — минуты, и чинить по одному значит потратить час на десятиминутную работу.

Исключение — дефект, который меняет смысл остальной проверки (сломанная камера, пустые кадры). Такое чини сразу и проверяй заново.

---

## Что проверять в двух форматах отдельно

Вертикаль — не кроп, и ломается она по-своему:

- вордмарк и длинные надписи упираются в края;
- веер, разложенный по горизонтали, выходит за рамку;
- нижняя треть занята интерфейсом площадки — держи безопасную зону шире;
- заголовок, который в горизонтали в одну строку, в вертикали должен переноситься.
