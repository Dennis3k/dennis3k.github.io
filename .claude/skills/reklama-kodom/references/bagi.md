# Ловушки

Каждая из них реально случилась и стоила перерендера. Прочти до того, как запустишь полный прогон — узнать симптом заранее дешевле, чем диагностировать после.

Общий принцип: **симптом почти никогда не указывает на причину.** Чёрный город — это не про город. Прямая вместо дуги — не про дугу. Сначала выведи числа, потом правь код.

---

## 1. Зеркало и чёрная геометрия: ориентация камеры

**Симптом.** Весь текст читается задом наперёд. Одновременно часть геометрии не рисуется вообще — сцена чёрная.

**Причина.** Вектор «вправо» посчитан как `cross(forward, up)` вместо `cross(up, forward)`. Базис становится левосторонним: картинка зеркалится, а обход вершин меняет знак, и отсев нелицевых граней выбрасывает именно те, что надо было показать.

**Лечение.**
```python
r = normalize(cross(up, forward))
u = cross(forward, r)
```
**Проверка.** Поставь куб в начало координат, камеру на −Z. Правая грань обязана быть справа. Две минуты сейчас экономят час потом.

---

## 2. Отсев граней вслепую

**Симптом.** Объекты то исчезают, то показывают изнанку.

**Причина.** Отсев по знаку векторного произведения в экранных координатах — корректен только при согласованном обходе всех граней, а при повороте объекта это легко нарушить.

**Лечение.** Для параллелепипедов, выровненных по осям, сравнивай положение камеры с плоскостью грани — это точно и не зависит от обхода:
```python
if cam.pos[1] > top_y:   faces.append(TOP)
if cam.pos[2] < front_z: faces.append(FRONT)
```
Для повёрнутых — векторное произведение, но зафиксируй один порядок вершин (TL, TR, BR, BL) для всех граней и проверь на кубе.

---

## 3. Точка пути за камерой рушит всю кривую

**Симптом.** Плавная дуга внезапно вырождается в прямую. Хуже всего тем, что это зависит от положения камеры: в одном кадре нормально, через секунду — прямая.

**Причина.** Один конец пути уехал за плоскость камеры. Проекция делит на z, близкий к нулю, координата улетает в миллионы, суммарная длина пути становится астрономической — и перепараметризация по длине дуги отдаёт на нужный участок три точки вместо полутора сотен.

**Лечение.** Два независимых пути вместо одного длинного, и отсечение за плоскостью камеры:
```python
def proj_clip(cam, pts3, min_z=0.18):
    sp, z = cam.project(pts3)
    ok = z > min_z
    return sp[ok] if ok.sum() >= 2 else None
```
Прогресс дели по времени (`0…0.62` подводка, `0.62…1` цель), а не по доле длины — тогда скачок проекции вообще ни на что не влияет.

**Диагностика.** Печатай суммарную экранную длину пути. Если она больше нескольких тысяч пикселей — что-то за камерой.

## 4. Метка исчезла, когда предмет осветили

**Симптом.** Печатный знак на коробке читался, подняли освещение — пропал.

**Причина.** Краска была светлее основы. На тёмном крафте оранжевый читался, на освещённом слился.

**Лечение.** Печать всегда **темнее** подложки: `(0.60, 0.28, 0.02)` на крафте, не `(0.98, 0.60, 0.04)`. Проверяй контраст после каждой правки освещения, а не один раз в начале.

## 5. Самопересекающийся контур вместо буквы

**Симптом.** Буква «w» вместо срезанных вершин получается с пиками и вырезами.

**Причина.** Зигзаг обведён одним контуром: левая граница, потом правая задом наперёд. Контур сам себя пересекает, заливка по правилу чётности выгрызает дыры.

**Лечение.** Каждый штрих — отдельный выпуклый четырёхугольник. Соседние делят общий торец, стыки получаются чистые, вершины срезанные:
```python
for i in range(len(pts) - 1):
    quad = [(ax-hx, ay), (ax+hx, ay), (bx+hx, by), (bx-hx, by)]
    fillPoly(mask, quad)
```
Правило: **в заливку — только выпуклые многоугольники.**

## 6. Квадратный ореол вокруг круглого предмета

**Симптом.** Вокруг скруглённой плитки висит заметный прямоугольник.

**Причина, их две.** Свечение построено по габаритной рамке, а не по собственной альфе. И размытие обрезано краем буфера: сигма сопоставима с полем.

**Лечение.** Ореол строй из альфы предмета, а поле бери с запасом — поле ≥ 2.5 сигмы:
```python
pad = int(sz * 1.05)
m = np.zeros((sz + 2*pad, sz + 2*pad), np.float32)
m[pad:pad+sz, pad:pad+sz] = alpha
glow(dst, m, sigmas=(sz*0.06, sz*0.18, sz*0.40), x=x0-pad, y=y0-pad)
```

## 7. Стык сцен читается как наплыв

**Симптом.** Вместо ухода в расфокус — двойная экспозиция: видно обе сцены сразу.

**Причина.** Уходящая сцена отрисована в отдельный буфер, её пост-эффекты (расфокус) записались в выброшенный словарь. Смешиваются две резкие картинки — а это и есть наплыв.

**Лечение.** Забери параметры уходящей сцены и примени их к её буферу до смешивания:
```python
f2 = {}
prev(tmp, L, t, cam2, f2)
tmp = blur(tmp, f2.get("blur", 0) + u * 16)
```
Стыки держи короткими: 0.10 с. Длинный плавный переход почти всегда читается как наплыв.

## 8. Герой уезжает за нижний край

**Симптом.** Предмет опускается, камера подъезжает — и предмет оказывается срезан рамкой.

**Причина.** Камера и предмет анимированы независимо. Кадрирование проверено на одном моменте, а не на всей траектории.

**Лечение.** Считай видимую высоту на дистанции и держи предмет в доле кадра:
```python
vis_h = 2 * dist * tan(radians(fov) / 2)
```
И проверяй кадрирование минимум в трёх точках движения: начало, середина, конец.

## 9. Нулевой кадр пустой

**Симптом.** Бриф говорит «кадр 0 уже в движении», а первые десять кадров — чернота.

**Причина.** Объект летит издалека с сильным ease-in. В первой половине времени он проходит проценты пути и физически находится за кадром.

**Лечение.** Смещай старт прогресса, а не ослабляй easing — ускорение нужно сохранить:
```python
u = 0.38 + 0.62 * ease_in_cubic(seg(t, 0, SLAM))
```
**Проверка.** Посчитай яркие пиксели в кадре 0. Ноль — значит кадр пустой.

## 10. Константа с чужим именем

**Симптом.** В коде `ORANGE`, в ней пурпур.

**Лечение.** Переименуй токен при перебрендировании, одним `sed` по всем файлам, и сразу прогони импорт. Три минуты против недели недоумения.

## 11. Надпись переехала при переводе

**Симптом.** После перевода кнопки и подсказки вылезают за поля, вордмарк упирается в край кадра.

**Причина.** Кегли и ширины подобраны под английский.

**Лечение.** После перевода пройди глазами **каждую** надпись в обоих форматах. Ширину вордмарка считай от ширины кадра с запасом 8–10 % на дугу и стрелку: `0.56` по горизонтали, `0.78` по вертикали — не больше.

---

## 12. Замены в коде не применились

**Симптом.** Скрипт отработал, а строки остались старые.

**Причина.** Искал `·`, а в файле лежит сам символ `·`. Или отступ отличается на пробел.

**Лечение.** После пакетной замены **всегда** проверяй результат:
```bash
grep -c "Wireless\|Add to Cart" *.py   # должно быть 0
```
Молчаливый `str.replace` — худший вид ошибки: он не падает.
