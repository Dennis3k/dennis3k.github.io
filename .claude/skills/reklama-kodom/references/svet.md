# Свет и объём

Плоскость даёт не геометрия, а свет. Проекция может быть безупречной — кадр всё равно читается как аппликация. Инстинкт «добавить ещё 3D» уводит не туда: добавлять надо свет.

Диагностика простая. Прищурься и посмотри на кадр как на пятна. Если предметы отличаются от фона только цветом заливки — плоско. Если у них есть кромка, разная резкость и они подсвечивают друг друга — объёмно.

---

## Проход 1. Контровой свет

Тонкая яркая линия изнутри силуэта плюс ореол снаружи, оба со смещением к источнику.

```python
rim_quad(dst, corners, color=(1.0, 0.56, 0.12), amount=0.30,
         halo=W*0.016, light=(-0.5, -0.9), edge=0.30)
```

| Параметр | Что это | Рабочее значение |
|---|---|---|
| `amount` | общая сила | 0.25–0.35 для телефона, 0.15–0.20 для дальних карточек |
| `halo` | радиус внешнего ореола | 1.0–1.8 % ширины кадра |
| `edge` | яркость внутренней кромки | 0.25–0.35 |
| `light` | откуда светит | обычно сверху-слева: `(-0.5, -0.9)` |

**Главная ошибка — передозировка.** При `amount` около 0.8 получается ровный неоновый контур: предмет выглядит наклейкой с обводкой, а не освещённым телом. Свет **скользит по краю**, то есть ярче с одной стороны и гаснет с другой. Если контур равномерный — убавь втрое и усиль направленность.

---

## Проход 2. Глубина резкости

Резка одна плоскость, остальное тает. Это единственный способ показать, что шесть предметов находятся на шести расстояниях.

```python
cam.focus = 3.45     # дистанция до плоскости фокуса
cam.dof   = 10.0     # пикселей размытия на единицу расфокуса
blur = cam.blur_for(z_объекта)
```

Фокус — драматургический инструмент, а не настройка. Переводи его: пока веер раскладывается, фокус едет с телефона на карточку-героя, и зритель понимает, куда смотреть, без единого слова.

Значения: `dof` 6–10 для сцен с предметами, 0 для титров. Сильнее 12 — каша.

---

## Проход 3. Световое пятно и блик

**Пятно** — свет, который яркая поверхность бросает на фон. Без него предметы не взаимодействуют и не находятся в одном пространстве.

```python
spill(dst, corners, color=(0.26, 0.31, 0.38), amount=0.20, sigma=W*0.085)
```
Сигма большая — 8–10 % ширины кадра. При маленькой сигме виден квадрат исходной формы, и это выглядит как ошибка.

**Блик** — косой отблеск на стекле. Один мягкий градиент поперёк экрана, `amount` 0.08–0.12. Больше — похоже на грязь.

---

## Проход 4. Среда

Чёрный фон — это отсутствие пространства. Предмет в нём висит, а не стоит.

Градиент пола, уходящий в темноту, плюс мягкое пятно света за героем. Держи темноту: вклад среды 0.4–0.5 от полной силы, иначе премиальность уходит.

```python
stage(dst, L, t, env=0.50)
```

Титровые сцены — исключение: там чёрный фон работает, потому что типографика и так плоская по природе, и среда ей только мешает.

## Форма предмета

Сильный разброс по граням делает куб кубом. Слабый — шестиугольным пятном.

```python
shades = {"top": 1.12, "front": 0.92, "right": 0.44, "left": 0.44}
```
Верх к боку — разница больше чем вдвое. Это выглядит преувеличенно в статике и абсолютно правильно в движении.

Для скруглённых тел вместо плоской заливки — вложенные контуры от тени к блику со смещением к источнику. Даёт гладкий градиент без единого шейдера:

```python
for i in range(n):
    u = i / (n - 1)
    цвет = lerp(тень, блик, u)
    размер = 1 - 0.55 * u
    смещение = (-0.03 * u, -0.05 * u)   # к источнику света
```

## Цветовая логика

**Акцент один, среда — его дополнение.** Оранжевая линия на синем городе. Пурпурная линия на голубом городе. Дополнительная пара заставляет акцент светиться без прибавки яркости.

Если акцент и среда одного тона, акцент пропадает — и чинить это яркостью бесполезно, кадр просто станет выжженным.

---

## Пост-цепочка

Порядок важен, он имитирует физику: сначала то, что происходит в объективе, потом на плёнке.

1. зум-смаз и общий расфокус (движение камеры)
2. блум от ярких областей (рассеяние в оптике)
3. хроматическая аберрация (дисперсия в стекле)
4. виньетка (падение света к краям)
5. зерно (плёнка)
6. плёночное плечо вместо жёсткого клиппинга (характеристическая кривая)

Плечо обязательно. Без него свет линии упирается в единицу и выглядит пластмассовым:
```python
knee = 0.78
hi = img > knee
img[hi] = knee + (1 - knee) * (1 - exp(-(img[hi] - knee) / (1 - knee)))
```
