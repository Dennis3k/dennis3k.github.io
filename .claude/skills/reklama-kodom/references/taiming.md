# Тайминг

## Тактовая сетка

Сначала музыка, потом картинка. Темп задаёт такт, такт задаёт монтаж.

```
BPM 100 → доля 60/100 = 0.6 с → такт (4 доли) = 2.4 с
```

Каждое событие ролика садится на тактовую линию:

| Такт | Время | Событие |
|---|---|---|
| 1 | 2.40 | телефон приземляется |
| 2 | 4.80 | страница товара |
| 3 | 7.20 | дроп, город |
| 4 | 9.60 | точка назначения |
| 5 | 12.00 | коробка касается земли |
| 7 | 16.80 | геройский удар |
| 8 | 19.20 | эндкард |

Тогда музыка не подложена под картинку — она её несущая конструкция.

**Проверь бриф на музыкальность.** Подели тайминги из брифа на длину такта. Делятся нацело — бриф уже написан ритмично, ничего не трогай. Не делятся — подвинь события к ближайшей линии; почти всегда становится лучше.

**Тишина перед ударом работает сильнее самого удара.** Полтакта пустоты, потом аккорд — и удар читается вдвое сильнее, чем если бы громкость просто выросла.

## Easing

Easing — это характер движения, и он говорит больше, чем сама траектория.

| Функция | Ощущение | Где |
|---|---|---|
| `ease_in_cubic` | разгон из покоя | влёт издалека |
| `ease_out_expo` | резкая остановка | удар, приземление |
| `ease_out_quint` | тяжёлая мягкая посадка | предмет садится на поверхность |
| `ease_in_out_cubic` | спокойный проезд | камера, панорама |
| `ease_in_out_quint` | длинный премиальный проезд | раскладка веера, долгий наезд |
| `ease_out_back` | перелёт и возврат | UI-элементы, уведомления |
| линейный | печать текста, бегущий свет | всё, что должно идти ровно |

**Линейный easing в движении предмета — всегда ошибка.** В природе ничто не стартует и не останавливается мгновенно.

**Перелёт нужен не всему.** Логотип с перелётом выглядит игрушечно. Уведомление без перелёта — мёртвым.

## Моушн-блюр

Не постэффект, а накопление подкадров: считаешь N положений внутри выдержки и усредняешь.

```python
shutter = 0.82          # доля кадра
t_i = t + (i/N - 0.5) * shutter / fps
```

Количество подкадров — по скорости, а не поровну:

| Что происходит | N |
|---|---|
| удар, влёт | 6–7 |
| пролёт сквозь экран | 6 |
| проезд камеры, раскладка | 4 |
| спокойная сцена | 2 |

Дорогие текстуры считай один раз на кадр и кешируй по параметрам, иначе подкадры умножают стоимость. Геометрия пересчитывается, текстура — нет: смазывается движение, а не содержимое.

## Непрерывность

«Один дубль без склеек» — не отсутствие монтажа, а отсутствие **жёстких** склеек. Сцены передают эстафету:

- уход в расфокус и выход из расфокуса
- пролёт сквозь яркую поверхность с пересветом
- предмет выходит из кадра, на его месте уже следующая сцена

Стык держи ≤ 0.10 с и обязательно размывай уходящую сцену. Длинный плавный переход между двумя резкими картинками читается как наплыв — то есть как склейка, которой ты избегал.
