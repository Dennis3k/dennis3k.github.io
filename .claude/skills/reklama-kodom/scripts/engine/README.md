# Движок

Рабочий, с вычищенными ловушками из `references/bagi.md`. Старт проекта:

```bash
cp core.py line.py render.py <проект>/
cp config_template.py <проект>/config.py
cp scenes_template.py <проект>/scenes.py
cd <проект> && python3 render.py --fmt 16x9 --scale 0.6 --stills 0.1,0.6,1.8,3.0
```

Контракт движка с проектом — два имени в `scenes.py`:

| Имя | Что делает |
|---|---|
| `layout(fmt)` | словарь раскладки под формат (обязательно) |
| `render_scene(dst, L, t, cam, fx)` | рисует кадр на момент `t` (обязательно) |
| `mb_samples(t)` | подкадры моушн-блюра по времени (необязательно, по умолчанию 2) |

`assets.py` с функцией `set_res(r)` подхватится, если он есть, — через неё текстуры в вертикали рисуются крупнее.

`fx` — словарь, которым сцена просит пост-обработку: `zoom` (зум-смаз), `blur` (общий расфокус), `glow` (множитель блума).

| Файл | Что внутри |
|---|---|
| `core.py` | easing, камера, перспективные квады, контровой свет, пятно, блик, `Tex`, кеш |
| `line.py` | `Path` и одна общая функция `draw_line` — носитель идеи |
| `render.py` | моушн-блюр, пост-цепочка, параллельная выдача кадров, режим стиллов |
