## Решения, которые не пересматриваются
- **Консистентность превыше всего:** лицо, одежда (льняная рубашка нараспашку, футболка с принтом, серо-коричневые льняные брюки, деревянные бусы), место (Seven Sisters, белая меловая гряда видна в каждом кадре с фоном), один источник света (светлая полоса у горизонта слева), палитра синего часа. Тон отдельного кадра не крутим, материал фона не подменяем; кадр, выпадающий из гаммы, перерабатываем (ракурс, действие, деталь, макролокация той же локации).
- Время идёт вперёд: каждый кадр не светлее предыдущего.
- С кадра 8 он **стоит и идёт**, он **босиком**; назад к сидению не возвращаемся.
- Он смотрит и движется **влево**, к светлой полосе.
- **Лицо читается и звучит голос — он поёт** (липсинк). Без липсинка только кадры без читаемого лица.
- В исходнике для sync.so: «губы работают на слогах, между фразами смыкаются», не «рот открыт».
- В промтах **не называть оборудование** (штатив, слайдер, дрон, объектив): модель его рисует. Камера описывается поведением.
- Ни одного кадра, повторяющего уже снятый по размеру и ракурсу.
- Герой не на кромке обрыва.
