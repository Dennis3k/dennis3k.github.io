# Сборка в CapCut

Порядок, который не приходится переделывать.

## 1. Проект

- Соотношение **9:16**, разрешение 1080×1920.
- Частота кадров проекта = один фпс на весь ролик (30, или родной 24/25 генераций). Выставить **до** импорта.
- Выключить автоматическое улучшение/стабилизацию при импорте — на ИИ-кадрах оно даёт артефакты.

## 2. Музыка первой

1. Положи трек на аудиодорожку.
2. Отметь маркерами: первый бит, границы блоков, точку дропа, финал.
3. Только после этого — импорт видео.

Маркеры по битам можно посчитать: `python3 scripts/beats.py --bpm <BPM> --offset <сек>`.

## 3. Нарезка

- Каждую генерацию обрезай сразу: убрать первые 0.3–0.5 с и последние 15–20%.
- Складывай годные интервалы на дорожку в порядке плана, без эффектов.
- Склейки ставь на 1–2 кадра раньше маркера бита (см. `ritm.md`), кроме дропа — там ровно по маркеру.
- Перебивки держи на отдельной верхней дорожке, чтобы можно было переставлять.

## 4. Проверка черновика

Прежде чем добавлять что-либо ещё: просмотр целиком, два раза, со звуком. Второй раз — на 2× без картинки, слушая ритм склеек. Правки ритма делаются здесь, а не после титров.

## 5. Звук

- Акценты — отдельной дорожкой, чтобы править уровни независимо.
- Атмосфера — ещё одной дорожкой на всю длину.
- Срез звука 0.2–0.4 с перед дропом.
- Громкость музыки под голосом — вручную по ключам, не авто-дакингом: авто срабатывает с запозданием и «качает».

## 6. Цвет

Коррекция покадрово (выравнивание), затем общий слой поверх всех (грейд). См. `cvet.md`.

## 7. Титры

В самом конце. Безопасные зоны и правила набора: `titry.md`.
Анимации появления по умолчанию — выключить.

## 8. Экспорт

| Параметр | Значение |
|---|---|
| Разрешение | 1080×1920 |
| Fps | как в проекте |
| Битрейт | «Рекомендуемый» или вручную 12–16 Мбит/с |
| Кодек | H.264 |
| Водяной знак | снять |

**Один экспорт.** Если после экспорта нашлась правка — правь в проекте и экспортируй заново из проекта, а не поверх готового файла.

## Частые грабли CapCut

- Фпс проекта меняется после импорта первого клипа — проверить перед финальным экспортом.
- Авто-субтитры ставят текст в нижнюю зону, перекрытую интерфейсом — поднять в безопасную зону вручную.
- Пресетные переходы навешиваются на все стыки одной кнопкой — проверить, что лишних нет.
- Экспорт в 60 fps из материала 24/25 fps не добавляет плавности, только размер файла.
