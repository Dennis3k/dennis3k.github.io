# Склейки и переходы

## Жёсткий стык — основа

90% склеек в вертикальном ролике — простой стык. Качество стыка задаётся **выбором кадров**, не эффектом между ними.

Стык держится, когда выполнено хотя бы одно:
- Внутри обоих кадров есть движение в момент склейки.
- Крупность меняется (общий → средний → крупный), не повторяется.
- Есть совпадение: форма, цвет, направление движения, положение объекта в кадре.
- Смена очевидна по смыслу: другая локация, другое время, другой персонаж.

Стык не держится, когда: оба кадра статичны, одинаковой крупности, с разным светом и без смысловой причины для смены. Эффект это не вылечит.

## Виды оправданных переходов

| Переход | Условие применения | Длина |
|---|---|---|
| Match cut | совпадение формы/цвета/движения в последнем и первом кадре | 0 (жёсткий стык) |
| Whip pan | быстрое движение камеры в одну сторону в обоих кадрах | 4–8 кадров смаза |
| Перекрытие объектом | что-то проходит перед камерой, закрывая кадр | по движению объекта |
| Speed ramp | есть удар/акцент, на который нужно «прилететь» | разгон 6–10 кадров |
| Затемнение | только смена главы или финал | 8–15 кадров |
| Белая вспышка | только на дроп, один раз за ролик | 2–4 кадра |

## Запреты

- **Пресетные глитчи, зумы, спины, «вжухи» как клей для несовпадающих кадров.** Это самый узнаваемый признак любительского монтажа. Если кадры не стыкуются — меняй кадры.
- **Больше одного вида перехода на ролик** (плюс один разовый акцент). Пять разных переходов в тридцати секундах = ролик про переходы, а не про содержание.
- **Кроссфейд между двумя ИИ-кадрами.** На полупрозрачности видно, что геометрия и свет не совпадают — хуже, чем жёсткий стык.
- **Переход на выдохе.** Длинный кадр начинается и заканчивается жёстко, иначе выдох перестаёт быть выдохом.

## J-cut и L-cut

Звук и картинка не обязаны переключаться одновременно.

- **J-cut:** звук следующего кадра приходит на 4–8 кадров раньше картинки. Тянет вперёд, хорош на эскалации.
- **L-cut:** звук предыдущего кадра продолжается после смены картинки. Склеивает блок, хорош на выдохе.

На ИИ-материале J/L-cut особенно полезны: непрерывный звук маскирует то, что картинка собрана из несвязанных генераций.

## Перебивки

Перебивка (инсерт) — короткий кадр детали на 0.3–0.8 с: рука, предмет, фрагмент фона, крупная деталь.

Для чего нужна:
- Разнести два кадра одной крупности.
- Спрятать дрейф лица между генерациями.
- Сжать время: «было → перебивка → стало».
- Дать акцент без смены локации.

**Держи в запасе 3–5 перебивок на каждый ролик.** Это самый дефицитный материал на монтаже: без них половина стыков не собирается, а догенерировать их обычно уже некогда.
