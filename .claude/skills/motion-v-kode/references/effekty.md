# Поваренная книга эффектов

Всё рисуется на canvas 2D. Каждый эффект — чистая функция от времени, завёрнутая в `save()/restore()`.

## Слэм слова

Слово «вылетает из глубины» и встаёт намертво на таймкоде слова. Разгон — `easeInQuart` (медленно, потом рывок), это читается как приближение к камере. После удара масштаб не фиксируется, а оседает затухающей пружиной:

```js
const RUSH = 0.14;                       // длина подлёта
const p = inv(w.t - RUSH, w.t, t);
let sc = lerp(0.24, 1, eInQuart(p));
if (t >= w.t) sc = 1 + 0.05 * decay(t - w.t, 9, 0.085);
const alpha = Math.pow(p, 0.55);
const blurPx = (1 - p) * 26 * u;         // расфокус глубины, поверх motion blur
```

Следующее слово не «сменяет» предыдущее плавно: предыдущее за 0.1 с разгоняется до ×1.5 и гаснет — как будто пробито насквозь.

Размер — подгонкой по ширине кадра с потолком по высоте. Чтобы одно слово было «самым большим», задавай каждому свою долю ширины (0.70–0.96), а не общий кегль: короткое слово на полную ширину получится крупнее длинного.

## Свечение и блик

```js
function glow(ctx, x, y, r, color, a) {
  const g = ctx.createRadialGradient(x, y, 0, x, y, r);
  g.addColorStop(0, rgba(color, a));
  g.addColorStop(0.45, rgba(color, a * 0.32));
  g.addColorStop(1, rgba(color, 0));
  ctx.fillStyle = g; ctx.beginPath(); ctx.arc(x, y, r, 0, TAU); ctx.fill();
}
```

На тёмном — `globalCompositeOperation = 'screen'`, на светлом — обычный `source-over` с низкой прозрачностью: `screen` на белом не даёт ничего.

**Блик не должен быть ярче и больше объекта, который украшает.** Белая вспышка радиусом ×4 и прозрачностью 0.6 поверх логотипа превращает логотип в белое пятно. Держи такие вспышки короткими (0.2 с) и в пределах 0.3–0.45 прозрачности.

## Шок-волна

Радиус растёт с замедлением, прозрачность падает квадратично, поверх — та же окружность с сильным блюром:

```js
const R = maxDim * max * (1 - Math.pow(1 - p, 2.2));
const a = Math.pow(1 - p, 2.0);
```

Толщина линии убывает вместе с прозрачностью (`12 * (1 - p)`), иначе кольцо выглядит нарисованным циркулем.

## Лучи скорости

Отрезки из центра наружу по сидированным углам, длина растёт как `p^0.6`, прозрачность падает как `(1-p)^1.6`. Работают только в паре с сильным motion blur — сами по себе читаются как графика, а не как скорость.

## Боке

Мягкие круги в «глубине»: радиальный градиент плюс тонкая окружность по краю на 0.78 радиуса — именно ободок читается как расфокус, а не просто пятно. Параллакс даётся общим множителем `z`, который медленно растёт: дальние пятна смещаются меньше ближних.

На светлой сцене `screen` не сработает — рисуй `source-over` синим с прозрачностью 0.2–0.35.

## Глянцевые 3D-буквы

Экструзия — та же строка, нарисованная N раз со смещением по вектору глубины, от дальней копии к ближней, с потемнением:

```js
for (let i = steps; i >= 1; i--) {
  const k = i / steps;
  ctx.fillStyle = `rgb(${lerp(10, 36, 1 - k)|0},${lerp(28, 86, 1 - k)|0},${lerp(86, 190, 1 - k)|0})`;
  ctx.fillText(txt, dx * k, dy * k);
}
```

Лицо — вертикальный градиент с «переломом» в середине (светлый верх → насыщенный → резко светлая полоса → тёмный низ). Этот перелом и читается как глянец. Сверху — та же строка белым градиентом сверху вниз с блюром в режиме `screen`: блик на верхней кромке.

Поворот в 3D подделывается матрицей `ctx.transform` — горизонтальное сжатие по косинусу рыскания плюс небольшой сдвиг. Для букв этого достаточно, настоящая проекция не нужна.

Контактная тень — сплющенный эллипс под объектом с блюром ~0.09 от кегля.

## Мокап телефона

Корпус — скруглённый прямоугольник с градиентом по диагонали (светлые рёбра, тёмная середина — так читается металл). Экран — вложенный прямоугольник, отступ ~2.8 % от высоты корпуса, с `clip()`, внутри которого содержимое рисуется в своих координатах `(0,0,w,h)` — это важно, иначе каждый элемент придётся пересчитывать в координаты кадра.

Поверх экрана — диагональный белый градиент с прозрачностью ~0.14: блик стекла. Без него телефон выглядит плоской картинкой.

Неоновая кромка: тот же контур, обведённый градиентом в `screen` с блюром ~3 % высоты.

## Постер и абстрактная графика

Композиция из трёх слоёв читается как «настоящая»: градиентная подложка, светящийся диск (солнце), силуэт гряды по синусоиде и слои-страты с `overlay`. Сверху — редкая сидированная «плёночная» крошка на прозрачности 0.06.

## Интерфейс

Текст, набираемый по символам, берёт позицию из карты тайминга, а не из счётчика кадров. Каждый новый символ получает короткий поп (`scale 1.16 → 1` за ~2 кадра) — без него набор выглядит мёртвым.

Морф микрофона в кнопку отправки делается перекрёстной прозрачностью двух глифов плюс растущий круг под ними: `alpha_mic = 1 - k`, `alpha_send = inv(0.55, 1, k)`. Стрелка появляется в последней трети — раньше читается каша.
