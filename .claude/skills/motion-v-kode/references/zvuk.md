# Звук кодом

Музыка и SFX синтезируются numpy по той же карте тайминга, что и картинка. Ни одного сэмпла — значит, при смене таймингов звук пересобирается вместе с видео, и хит всегда стоит на своём кадре.

Готовый набор примитивов — `scripts/score_kit.py`: огибающие, биквады, шум, свипы, пэды, пластинчатая реверберация, компрессор, лимитер, измеритель LUFS, запись 24-бит WAV.

## Сетка

Темп задаётся в долях, а не в секундах: 120 BPM → доля 0.5 с → 15 кадров при 30 fps. Удобно, когда музыка и монтаж делят одну сетку. Но **голос главнее сетки**: если слово приходит не на долю, хит ставится по слову, а не по доле.

## Из чего собирается

| Элемент | Как |
|---|---|
| Суб-удар | синус со свипом 62→30 Гц, экспоненциальная огибающая, мягкое насыщение `tanh` |
| Импакт | шумовой всплеск через ФНЧ + низкий тон + щелчок в первые 8 мс |
| «Присос» перед ударом | шум с нарастающей огибающей `linspace(0,1)^2.2`, ставится **до** удара |
| Вуш | шум через ФНЧ с огибающей `sin(0..π)^1.6` |
| Тик набора | синус 2.1–2.4 кГц + шум, затухание 6 мс |
| Пэд | две расстроенные пилы на голос аккорда, ФНЧ, медленная ADSR |
| Колокол | 5 негармонических частичных с разным затуханием |
| Райзер | шум между двумя статичными ФНЧ с кроссфейдом + свип-синус |

Длинные фильтры считай через FFT (`fft_lowpass`), а не биквадом в цикле: питоновский цикл на 1.25 млн отсчётов — это секунды на каждый вызов.

## Дак под голос

Дак режется **заранее**, по карте слов, даже если голоса ещё нет:

```python
for w, at in VO_WORDS:
    dur = 0.06 * len(w) + 0.20          # оценка длины слова
    # −9 дБ на окне слова, атака 35 мс, отпускание 220 мс
```

Готовую огибающую сгладь окном Ханна ~30 мс, иначе на каждом слове будет щелчок. Когда придёт настоящая озвучка, дак уже стоит в нужных местах.

## Громкость

Меряй, а не прикидывай. K-взвешивание по BS.1770 — два биквада, дальше блоки 400 мс с шагом 100 мс и гейтингом:

```
LUFS = −0.691 + 10·log10(Σ по каналам mean(k²))
```

Цель мастера −14 LUFS / −1 dBTP. Нормализация в одиночку не доводит: лимитер съедает громкость обратно. Рабочая схема — компрессор на шину (−22 дБ, 3.2:1), затем 3–4 цикла «нормализовать → лимитировать».

**Музыкальная подложка без голоса должна сидеть примерно на 1.5 дБ ниже цели.** Голос идёт на 9 дБ громче всего остального и сам дотянет интеграл до −14. Если подложку уже выжать до −14, с голосом мастер уедет в перегруз.

True peak считай с четырёхкратным передискретированием через FFT: обычный пик по отсчётам врёт на 0.5–1 дБ.

## Стемы, которые сходятся в мастер

Чтобы из стемов можно было собрать проект для монтажёра, они должны суммироваться ровно в выданный микс. Для этого весь мастер-тракт собирается **одной кривой усиления**, и она применяется к каждому стему по отдельности:

```python
G = np.ones(N)
g = compress(mix, ...); G *= g; mix = mix * g
for _ in range(4):
    k = 10**((-14.0 - lufs(mix)) / 20); G *= k; mix = mix * k
    g = limiter(mix, ceiling);          G *= g; mix = mix * g
stem_music_out = stem_music * G         # сумма стемов == мастер
```

Проверяется одной строкой: максимум модуля разности суммы стемов и мастера. Ниже −200 dBFS — сошлось. Если прогонять каждый стем через лимитер отдельно, не сойдётся никогда.

## Сведение с картинкой

```bash
ffmpeg -i master.mp4 -i score.wav -map 0:v -map 1:a -c:v copy \
       -c:a aac -b:a 320k -ar 48000 -ac 2 -shortest -movflags +faststart out.mp4
```

Видео копируется без перекодирования — звук не повод пережимать картинку второй раз.
