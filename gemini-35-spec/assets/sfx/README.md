# Куда класть звуки

Файлы кладутся **сюда**, в `gemini-35-spec/assets/sfx/`, с именем слота:
`impact_big.wav`, `whoosh_long.mp3` и так далее. Расширение любое — wav, mp3,
aiff, flac; частота дискретизации любая; моно или стерео. Остальное делается
само: приведение к 48 кГц, обрезка тишины в начале (чтобы удар сел ровно на
таймкод) и нормализация по пику.

Слот не заполнен — на его месте остаётся синтезированный звук. Можно заполнять
по одному и слушать после каждого.

Проверить, что подхватилось:

```bash
python3 -I tools/sfxlib.py      # покажет заполненные и пустые слоты
python3 -I tools/score.py       # пересоберёт звук, ~20 с
bash tools/mux.sh gemini35_16x9 gemini35_9x16
```

## Эти файлы не попадают в git

Папка исключена в `.gitignore`. Лицензия Epidemic Sound разрешает распространять
готовое произведение, но **не сами звуковые файлы** — а репозиторий публичный.
Pixabay это разрешает, но правило оставлено общим, чтобы не перепутать источники.

## Что искать

Порядок по важности: первые пять слотов меняют ролик сильнее, чем остальные
тринадцать вместе взятые.

| Слот | Что это в ролике | Запрос на поиск | Чего избегать |
|---|---|---|---|
| **impact_big** | удар на «All answered», 16.15 с — главный момент | `cinematic impact`, `trailer hit`, `braam` | длинных хвостов больше 2 с |
| **slam_1…slam_4** | четыре удара хука, 0.1–1.6 с. Четвёртый («FASTER.») крупнее остальных | `text impact`, `logo hit`, `punch` | одинаковых — возьми четыре разных |
| **whoosh_long** | пролёты камеры, 0.7–1.3 с | `cinematic whoosh`, `transition swoosh` | «ветра» без атаки |
| **suck** | нарастание **перед** ударом, 0.3 с | `reverse whoosh`, `suck in`, `riser short` | длиннее 0.5 с |
| **riser_build** | разгон перед главным дропом, 12.8–16 с | `tension riser 3 seconds`, `build up` | с ударом в конце — удар уже свой |
| impact_mid | дроп на «3.5» и удар на логотипе | `impact medium`, `sub drop hit` | |
| impact_soft | приземления, мелкие акценты | `soft impact`, `thud` | |
| sub_drop | низ под дропами | `sub drop`, `808 boom`, `sub bass hit` | всего, что выше 120 Гц |
| whoosh_short | быстрые переходы, 0.3–0.5 с | `short whoosh`, `swish` | |
| crash | тарелка на дропах | `cymbal crash` | |
| crash_rev | обратная тарелка перед дропом | `reverse cymbal` | |
| click_ui | щелчки интерфейса | `ui click`, `button click` | «мышиных» щелчков из игр |
| tap | тап по кнопке отправки, 12.5 с | `ui tap`, `send confirm` | |
| tick_type | одна набранная буква — звучит 29 раз подряд | `keyboard key single`, `type click` | всего, что длиннее 60 мс |
| twinkle | искорка на блике логотипа | `sparkle`, `magic chime short` | мелодических фраз |

### Два правила, которые важнее выбора звука

**Тишина в начале файла.** Весь ролик смонтирован по кадрам: удар должен попасть
в кадр 485, а не в 487. Обрезка стоит автоматическая, но если в сэмпле плавное
нарастание — она срежет и его. Для `impact_*` и `slam_*` бери файлы с резкой
атакой.

**`tick_type` звучит 29 раз подряд** за 1.3 секунды. Любой заметный хвост
превратит набор текста в кашу. Нужен сухой щелчок короче 60 мс.
